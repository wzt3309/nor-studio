# Agent instructions

## Language

Use English by default for project documentation and code comments.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues. Before tracker operations, read
`docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging, read
`docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. Before domain exploration or architectural changes,
read `docs/agents/domain.md`.
